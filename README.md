# Kanzlei-AI-Skills
Dieses Repo enthält alle Skills in den jeweils gültigen Fassungen, die wir für die Kanzlei entwickelt haben.

- [BK Monatsbuchhaltung v1.4.0](bk-monatsbuchhaltung/SKILL.md): Rot/Grün mit Buchungsstapel und Klärungsstapel je Monat, Schleppschutz gegen leere Felder beim DATEV-Import, Kostenstellen nach Mandantenprofil und getrennte Buchungsvorläufe. [Installationspaket herunterladen](outputs/bk-monatsbuchhaltung-v1.4.0.zip). Vorversion: [v1.3.0](outputs/bk-monatsbuchhaltung-v1.3.0.zip).
- [DATEV E-Mail-DMS-Ablage v1.2.0](datev-email-dms-ablage/skills/email-dms-ablage/SKILL.md): Ablage von Outlook-E-Mails als EML im DATEV-DMS über Riecken mCO. Original-EML vorrangig; rekonstruierte EML aus den Connector-Daten (`scripts/build_eml.py`) nur mit ausdrücklicher Nutzerfreigabe und klarer Kennzeichnung. Ablage-Knigge (357 Regeln), expliziter Bearbeitungsstatus, geprüfte Dateiübergabe, Rücklesekontrolle mit Dokument-ID. [Installationspaket herunterladen](outputs/datev-email-dms-ablage-v1.2.0.zip), [Testbericht v1.1.0](outputs/datev-email-dms-ablage-v1.1.0-testbericht.json). Vorversionen: [v1.1.0](outputs/datev-email-dms-ablage-v1.1.0.zip), [v1.0.0](outputs/datev-email-dms-ablage-v1.0.0.zip).
