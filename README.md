# Kanzlei-AI-Skills
Dieses Repo enthält alle Skills in den jeweils gültigen Fassungen, die wir für die Kanzlei entwickelt haben.

- [BK Monatsbuchhaltung v1.4.1](bk-monatsbuchhaltung/SKILL.md): Durchführungspflicht bis zum Abschluss-Gate (kein vorzeitiger Abbruch, Endstatus je Eingabedatei, technische Einzelfehler nur lokal blockierend), Klärungsquote mit Zweitprüfung und Klärungsquoten-Nachweis, Abgrenzungsregister bei HTTP 403 ohne Nullstandsannahme, Belegdateiregel „ein Buchungsbeleg = genau eine eigene PDF-Datei“ mit `scripts/beleg_pdf.py`; weiterhin Rot/Grün mit Buchungsstapel und Klärungsstapel je Monat, Schleppschutz, Kostenstellen und getrennte Buchungsvorläufe. [Installationspaket herunterladen](outputs/bk-monatsbuchhaltung-v1.4.1.skill) ([Testbericht](outputs/bk-monatsbuchhaltung-v1.4.1-testbericht.json)). Vorversionen: [v1.4.0](outputs/bk-monatsbuchhaltung-v1.4.0.zip), [v1.3.0](outputs/bk-monatsbuchhaltung-v1.3.0.zip).
- [DATEV E-Mail-DMS-Ablage v1.2.0](datev-email-dms-ablage/skills/email-dms-ablage/SKILL.md): Ablage von Outlook-E-Mails als EML im DATEV-DMS über Riecken mCO. Original-EML vorrangig; rekonstruierte EML aus den Connector-Daten (`scripts/build_eml.py`) nur mit ausdrücklicher Nutzerfreigabe und klarer Kennzeichnung. Ablage-Knigge (357 Regeln), expliziter Bearbeitungsstatus, geprüfte Dateiübergabe, Rücklesekontrolle mit Dokument-ID. [Installationspaket herunterladen](outputs/datev-email-dms-ablage-v1.2.0.zip), Testberichte [v1.2.0](outputs/datev-email-dms-ablage-v1.2.0-testbericht.json) und [v1.1.0](outputs/datev-email-dms-ablage-v1.1.0-testbericht.json). Vorversionen: [v1.1.0](outputs/datev-email-dms-ablage-v1.1.0.zip), [v1.0.0](outputs/datev-email-dms-ablage-v1.0.0.zip).
