# Kanzlei-AI-Skills
Dieses Repo enthält alle Skills in den jeweils gültigen Fassungen, die wir für die Kanzlei entwickelt haben.

- [BK Monatsbuchhaltung v1.5.0](bk-monatsbuchhaltung/SKILL.md): neuer Abschnitt 5 „Übertragung über den Riecken-Connector“ (nur auf ausdrücklichen Auftrag nach der Paketübergabe): Personenkonten, Buchungsstapel `Eingangsrechnungen` und Klärungsposten je Monat über Riecken nach DATEV, rote Vorgänge über das Klärungskonto aus dem Mandantenprofil (Kanzleistandard 159900, Arbeitskonto mit Zielsaldo 0) mit KLÄR-Buchungstext, keine Platzhalterbeträge, Nutzerentscheidungen mit Name und Datum, Prüfungs-Excel auf Riecken-Stand mit Blatt `Riecken-Übertragung` und Statusdatei; Hilfsskripte `riecken_records.py`, `update_review_workbook_riecken.py`, `remove_document_from_transfer.py`. Der Paketvertrag der Skripte bleibt 1.4.1 (Durchführungspflicht, Klärungsquote, Belegdateiregel, Rot/Grün mit Buchungsstapel und Klärungsstapel, Schleppschutz, Kostenstellen, getrennte Buchungsvorläufe).
