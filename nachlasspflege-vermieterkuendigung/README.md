# Nachlasspflege – Vermieterkündigung

Privater Skill für standardisierte Wohnungskündigungen in Nachlasspflegschaften.

Standardausgabe je Fall:
1. neu formuliertes Vermieterschreiben ohne Wasserzeichen,
2. Mietaufhebungsvertrag auf Basis der eingebetteten Kanzleivorlage `Mietaufhebungsvertrag.docx` mit Wasserzeichen „Entwurf“.

Beide Word-Dateien werden immer im Chat ausgegeben, sofern der Anwender nicht ausdrücklich nur eine Datei verlangt. DMS-Ablagen für Sara erfolgen mit dem ausdrücklich übergebenen Bearbeitungsstatus „offen“ und werden anschließend anhand der Dokument-ID kontrolliert.

Die Word-Vorlage ist zusätzlich als textgetreue Fallback-Fassung im Skill hinterlegt, falls die DOCX-Datei in einem Lauf technisch nicht direkt lesbar ist.
